# SW426 Student CRUD REST API

Backend lab project for **Software Quality Engineering (SW426)** — *Creating & Testing Backend API using Postman for CRUD Operations*.

This API manages **student records** with full **Create, Read, Update, Delete (CRUD)** operations, **MongoDB** persistence, **JSON** request/response bodies, validation, consistent error handling, **Postman** tests, and **automated Node.js tests**.

**Sample student (primary documentation data):**

| Field        | Value                 |
|-------------|------------------------|
| Name        | Shahbaz Raza           |
| Roll No     | K22SW035               |
| Department  | Software Engineering   |
| Semester    | 8                      |

---

## Project objectives

- Demonstrate RESTful CRUD on a single entity (`Student`).
- Persist data in MongoDB so records survive server restarts.
- Return correct HTTP status codes and JSON error messages.
- Test manually with Postman and automatically with Node’s built-in test runner.

## Database design — Student schema

| Field        | Type   | Rules                                      |
|-------------|--------|--------------------------------------------|
| `name`      | String | Required, trimmed, non-empty               |
| `rollNo`    | String | Required, trimmed, unique                  |
| `department`| String | Required, trimmed, non-empty               |
| `semester`  | Number | Required, integer, **1–8**                 |
| `_id`       | ObjectId | Auto-generated by MongoDB                |
| `createdAt` | Date   | Auto (Mongoose timestamps)                 |
| `updatedAt` | Date   | Auto (Mongoose timestamps)                 |

Default local database name: **`sqe_students`**  
Automated tests use **`sqe_students_test`** (separate database — your main data is not wiped when you run tests).

## Configure environment (`.env`)

1. Copy the example file:

   **PowerShell:**

   ```powershell
   Copy-Item .env.example .env
   ```

   **CMD:**

   ```cmd
   copy .env.example .env
   ```

2. Edit `.env`:

   ```env
   PORT=3000
   NODE_ENV=development
   MONGODB_URI=mongodb://127.0.0.1:27017/sqe_students
   MONGODB_URI_TEST=mongodb://127.0.0.1:27017/sqe_students_test
   ```

3. **Atlas:** Replace `MONGODB_URI` with your Atlas URI (never commit real passwords). Keep placeholders in `.env.example` only.

## Start MongoDB (local)

- If MongoDB is installed as a **Windows service**, start **MongoDB Server** from Services (`services.msc`) or:

  ```powershell
  net start MongoDB
  ```

- If you use **MongoDB Compass**, connect to `mongodb://127.0.0.1:27017` to confirm the server is running.

If MongoDB is not running, the API will fail on startup with a connection error.

## API reference

**Base URL:** `http://localhost:3000/api/students`

### Create — `POST /api/students`

**Body:**

```json
{
  "name": "Shahbaz Raza",
  "rollNo": "K22SW035",
  "department": "Software Engineering",
  "semester": 8
}
```

| Result              | Status |
|---------------------|--------|
| Created             | **201** |
| Validation error    | **400** |
| Duplicate `rollNo`  | **409** |
| Invalid JSON        | **400** |

**Success example:**

```json
{
  "success": true,
  "message": "Student created successfully",
  "data": {
    "_id": "674abc1234567890abcdef01",
    "name": "Shahbaz Raza",
    "rollNo": "K22SW035",
    "department": "Software Engineering",
    "semester": 8,
    "createdAt": "2026-10-27T10:00:00.000Z",
    "updatedAt": "2026-10-27T10:00:00.000Z"
  }
}
```

---

### Read all — `GET /api/students`

| Result        | Status |
|---------------|--------|
| Success       | **200** (array, may be empty) |

---

### Read one — `GET /api/students/:id`

| Result                         | Status |
|--------------------------------|--------|
| Found                          | **200** |
| Malformed ID (not 24-char hex) | **400** |
| Valid ID, no document          | **404** |

**400 vs 404:** A string like `not-an-id` is **not** a valid MongoDB ObjectId → **400 Invalid student ID format**. A valid-looking ID such as `507f1f77bcf86cd799439011` with no matching student → **404 Student not found**.

---

### Update — `PUT /api/students/:id`

**Body (partial or full allowed fields only):**

```json
{
  "name": "Shahbaz Raza",
  "rollNo": "K22SW035",
  "department": "Software Engineering",
  "semester": 7
}
```

| Result              | Status |
|---------------------|--------|
| Updated             | **200** |
| Not found           | **404** |
| Bad ID              | **400** |
| Validation / dup    | **400** / **409** |
| `_id` in body       | **400** |

---

### Delete — `DELETE /api/students/:id`

| Result    | Status |
|-----------|--------|
| Deleted   | **200** with confirmation JSON |
| Not found | **404** |
| Bad ID    | **400** |

After delete, `GET` the same `:id` must return **404**.

## Postman testing

### Import files

1. Open Postman → **Import**.
2. Select:
   - `postman/SW426 Student CRUD API.postman_collection.json`
   - `postman/SW426 Local Environment.postman_environment.json`
3. Enable environment **SW426 Local Environment** (top-right).

### Run tests

1. Start the API (`npm start`) and MongoDB.
2. Open collection **SW426 Student CRUD API**.
3. Run folder **1. Happy Path (run in order)** top to bottom (uses collection variable `studentId` from the create response).
4. Run folder **2. Validation and errors** for error scenarios (items 7–14).
5. Use **Run collection** to execute all requests; check the **Test Results** tab.

Collection variables:

| Variable    | Purpose                          |
|------------|-----------------------------------|
| `baseUrl`  | Default `http://localhost:3000`   |
| `studentId`| Set automatically after create    |

## Troubleshooting

| Issue | What to do |
|-------|------------|
| `ECONNREFUSED` MongoDB | Start MongoDB service or fix `MONGODB_URI` |
| Port 3000 in use | Change `PORT` in `.env` and Postman `baseUrl` |
| 409 on create in Postman | Roll number already exists — use a new `rollNo` or delete the record |
| Tests fail to connect | Ensure MongoDB is running and `MONGODB_URI_TEST` is correct |
